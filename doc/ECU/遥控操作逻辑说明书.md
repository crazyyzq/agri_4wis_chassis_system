# 农业四轮独立转向底盘 ECU 遥控操作逻辑说明书

版本：V1.0  
日期：2026-07-09  
适用范围：当前 CPU0 主控程序与 16 通道 SBUS 遥控器

## 1. 使用前必须确认

1. 本说明书描述的是当前代码逻辑，不代表所有硬件功能已经实车验证。
2. 默认 CMake 构建配置为 `safe`，并保持 `ECU_COMMISSIONING_STEER_ONLY_MODE=1`；该固件不会输出整车行走命令。只有经过明确审批并构建 `whole_vehicle_motion` 配置后，才允许进行悬空轮或整车运动调试。
3. 上电操作前，车辆必须处于 P 档、油门最低、转向与调节摇杆回中、急停已解除，人员远离车轮、转向机构、支腿和液压机构。
4. 模式切换、档位切换或液压动作被 ECU 拒绝时，不要反复快速拨动开关。先回到安全中位，查看调试串口中的拒绝原因。
5. 变轮距阀组已确认：阀 3 缩短液压杆（变窄），阀 4 伸长液压杆（变宽）。后悬挂阀组仍等待接线语义确认，因此相应遥控动作保持关闭。

## 2. 遥控通道定义

| 通道 | 遥控器操作件 | 当前功能 |
|---|---|---|
| CH1 | 右摇杆左右 | 阿克曼转向输入 |
| CH2 | 右摇杆上下 | HOME 中位时调节四腿地隙 |
| CH3 | 左摇杆上下 | 行走油门 |
| CH4 | 左摇杆左右 | 高压上电/下电请求 |
| CH5 | 三档开关 | 驾驶域为 D/P/R；调节域为悬挂伸缩方向 |
| CH6 | 右肩按键 | 右转向灯 |
| CH7 | L2 按键 | 自动/人工控制权 |
| CH8 | HOME 键 | 选择阿克曼、调节或特殊模式域 |
| CH9 | B2 按键 | 双闪 |
| CH10 | B1 按键 | 喇叭 |
| CH11 | L1 按键 | 大灯 |
| CH12 | 左肩按键 | 左转向灯 |
| CH13 | 暂停按键 | 急停触发/急停复位 |
| CH14 | 右肩波轮 | HOME 中位时调节轮距 |
| CH15 | R1 按键 | 正阿克曼/自转/前悬挂选择 |
| CH16 | R2 按键 | 反阿克曼/蟹行/后悬挂选择 |

SBUS 原始 11 位值由 ECU 转换为 1050～1950 的 PPM 等效值。离散开关判定区间为：

- 低位：不高于 1200；
- 中位：1400～1600；
- 高位：不低于 1800；
- 两个间隔区属于过渡区，不立即生成新操作事件；
- 普通离散输入需要稳定 80 ms 才生效。

## 3. 推荐上电流程

1. 打开遥控器并确认接收机已连接。
2. 将 CH5 放在 P 档，CH3 放到最低，CH1、CH2、CH4、CH14 回中。
3. 等待 SBUS 链路连续可信 1 s。
4. 如果急停已锁存，将 CH13 放到中位并保持至少 1 s，直到急停解除。
5. 将 CH4 向右拨到高位并保持至少 350 ms。
6. ECU 检查 P 档、零速、低油门、转向中立、无急停、无 A 类故障以及 CAN1 电源网络在线。
7. 条件满足后，MOS6 保持导通并请求电池高压。只有 BMS 确认高压稳定后，ECU 才启动 DCDC 12 V、逆变器及具备条件的伺服驱动器。

不满足上电条件时，本次请求直接拒绝，不会在条件稍后满足时自动补执行。应先将 CH4 回中，排除原因后重新操作。

## 4. 急停操作

### 4.1 触发急停

CH13 是“任意稳定位置变化即急停”，不是固定某一端才急停：

- 低位变中位；
- 中位变高位；
- 高位变中位；
- 中位变低位；
- 高位直接变低位或反向变化。

任一变化经稳定判定后都会锁存急停。SBUS 超时、接收机 failsafe、连续解码错误或遥控数据可信度错误也会锁存急停。

急停后，ECU 发出明确的零速和安全执行意图，停止液压动作并进入受控停车。急停不是简单停止刷新旧命令。

### 4.2 解除急停

1. 确认车辆已经零速、抱闸有效且没有 A 类故障。
2. 将 CH13 放到中位。
3. 保持中位至少 1 s，直到诊断状态显示急停清除。

只短暂经过中位不能解除急停。

## 5. HOME 三个模式域

| HOME 位置 | 模式域 | R1 | R2 |
|---|---|---|---|
| 低位 | 阿克曼域 | 正阿克曼 | 反阿克曼 |
| 中位 | 调节域 | 选择前悬挂 | 选择后悬挂 |
| 高位 | 特殊域 | 自转 | 蟹行 |

HOME 切换后有 150 ms 事件保护时间。切换前已经保持的 R1/R2 状态不会被当作新命令，防止跨域误触发。

R1/R2 按“状态变化事件”处理，不依赖按钮最终是高位还是低位：

- 操作一次 R1 就选择 R1 对应功能；
- 再操作 R1 仍保持该功能；
- 只有操作 R2 才切换到 R2 对应功能，反之亦然。

进入 HOME 低位时默认正阿克曼；进入 HOME 高位时默认自转；进入 HOME 中位时默认选择前悬挂。模式变化只有在 P 档、零速、低油门、转向中立、无急停、无 A 类故障且没有其他模式过渡时才会被接受。

## 6. 行走和四轮转向

### 6.1 D/P/R 档

- CH5 高位：D 档；
- CH5 中位：P 档；
- CH5 低位：R 档。

从 P 切入 D 或 R 前，CH3 必须先处于低位。车辆运动中禁止直接在 D 与 R 之间切换；必须先回 P 并确认零速。

P 档禁止行走，但允许轮子转到当前模式要求的目标角度，便于驾驶员在起步前观察正阿克曼、反阿克曼、自转或蟹行姿态。

### 6.2 正阿克曼

操作：

1. HOME 置低位；
2. 首次进入时默认正阿克曼，也可操作一次 R1 明确选择；
3. CH1 向左，车辆按车头方向向左转；CH1 向右，车辆按车头方向向右转；
4. CH5 选择 D/R，CH3 从低位平稳增加油门。

当前阿克曼最大转角限制为 ±50°。四个转向目标由同一次遥控采样统一计算。

### 6.3 反阿克曼

操作：

1. HOME 置低位；
2. 操作一次 R2；
3. 车尾成为驾驶员认知中的前进方向；
4. D 档表示向原车尾方向行驶；
5. CH1 向左时，车辆仍向当前前进方向的左侧转，不要求驾驶员反向操作摇杆。

### 6.4 自转

操作：

1. 车辆停车并置 P；
2. HOME 置高位，首次进入默认自转，也可操作一次 R1；
3. 四轮先转到 45° 自转姿态；
4. ECU 根据四个转向电机实际位置确认到位后，才允许行走轮动作；
5. CH5 的 D/R 选择两个自转方向，CH3 控制自转速度。

CH1 在自转模式中不参与转向。

### 6.5 蟹行

操作：

1. 车辆停车并置 P；
2. HOME 置高位；
3. 操作一次 R2；
4. 四个轮子先统一转到固定 +90° 绝对位置；
5. ECU 确认四轮到位后才允许行走；
6. D/R 只改变横向移动方向，不改变 +90° 转向姿态。

蟹行模式不依赖 CH1。当前约定为 D 档整车向左横移、R 档整车向右横移；最终方向仍需以整车实测为准。

## 7. HOME 中位调节域

进入条件：HOME 中位、车辆零速、低油门、转向中立、无急停和 A 类故障。进入调节域后，实际行驶档被强制保持为 P，CH5 仅作为液压悬挂方向选择，不会驱动车轮行走。

CH2 变地隙、CH14 变轮距和 CH5 悬挂控制是相互独立的请求，R1/R2 只选择前后悬挂，不影响 CH2 或 CH14。最终输出仍受阀组互锁和安全层限制。

### 7.1 CH2 四腿变地隙

- CH2 大于 1850：四条腿向上伸，抬升电机反转，位置计数向负方向变化；
- CH2 小于 1150：四条腿回收，抬升电机正转，位置计数向正方向变化；
- CH2 在 1150～1850：保持当前位置。

运动速度不随摇杆幅度变化。四腿使用 CAN3 同步插补，从实时反馈位置开始生成下一组位置点。测试阶段软限位为：

- 最短位置：`-10000 counts`；
- 最长位置：`-8000000 counts`。

缺少新鲜位置反馈、CAN3 超时、软限位或关键故障时，ECU 不再下发新的运动点。

### 7.2 CH14 变轮距

- CH14 大于 1850：请求液压杆向外伸；
- CH14 小于 1150：请求液压杆回收；
- CH14 在 1150～1850：停止。

当前映射为：

- CH14 大于 1850：阀 4 打开，液压杆伸长，轮距变宽；
- CH14 小于 1150：阀 3 打开，液压杆缩短，轮距变窄。

### 7.3 前后液压悬挂

进入 HOME 中位后默认选择前悬挂：

- 操作一次 R1：选择前悬挂；
- 操作一次 R2：选择后悬挂；
- CH5=D：向上抬，液压杆回收；
- CH5=P：停止；
- CH5=R：向下降，液压杆伸出。

当前前悬挂映射已确认为阀 1 回收液压杆（抬升）、阀 2 伸长液压杆（下降）。后悬挂阀组尚未确认并配置为 0，因此选择后悬挂时不会启动液压站。

液压站 Node13 仅允许反转。当前工作转速为 1000 rpm，可配置范围为停机 0 rpm、工作最高 2400 rpm。存在有效液压请求时，ECU 先保持所有阀关闭并启动液压站；只有 Node13 的新鲜 TPDO 反馈连续确认实际反转速度超过 800 rpm 后，才允许打开目标阀。反馈过期、故障、转速不足、CAN3 离线、操作回中或请求互锁失败时立即关阀；无液压请求时液压站停止。阀向切换时至少保留一个 10 ms 的全关断周期。

阀 1/2、阀 3/4、阀 5/6 分别为互斥对，任一对不能同时打开。软件检测到同对双阀请求时会关闭该对阀，不允许带着冲突请求启动液压站。

## 8. 灯光、喇叭和控制权

- CH6 高位：右转向灯；
- CH12 高位：左转向灯；
- CH9 高位：用户双闪；
- CH10 高位：喇叭；
- CH11 高位：大灯；
- CH7 中位：请求自动控制；
- CH7 低位或高位：人工控制。

灯光优先级为：安全双闪 > 用户双闪 > 左/右转向灯 > 关闭。安全双闪期间喇叭请求被抑制。

自动控制只允许在 HOME 低位的正/反阿克曼域申请，并要求 P 档、零速、低油门、转向中立、无过渡、无急停和有效的外部自动请求。驾驶员操作 CH1、CH3、CH5、HOME 或将 CH7 离开中位会触发人工接管；接管后必须将油门重新回到低位。

## 9. 下电流程

1. 松开油门并回 P 档；
2. 等待车辆零速、抱闸有效、液压站停止、液压阀关闭且无模式过渡；
3. 将 CH4 向左拨到低位并保持至少 350 ms；
4. ECU 撤销高压请求并释放 MOS6。

急停或 A 类故障会触发保护下电意图，但正常操作仍应按以上顺序完成。不要用直接断低压电源代替正常停车和下电。

## 10. 当前未完成的现场确认

以下项目没有硬件验证结果前，不得写成“已可用”：

1. 后悬挂使用的阀组及方向；
2. 蟹行 D 向左、R 向右的整车实测方向；
3. 四腿同步、软限位、位置差恢复和单轴故障策略的整车液压负载验证；
4. Node13 液压站反转方向、1000 rpm 工作点、800 rpm 开阀门槛及最高 2400 rpm 限制的负载验证。

现场确认阀组后，只修改 `ecu/config/include/ecu_config.h` 中对应的配置宏，并补充台架测试记录；不要把阀号或方向写入遥控状态机、仲裁器或设备层。
