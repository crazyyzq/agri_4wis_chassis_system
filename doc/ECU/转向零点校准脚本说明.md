# 转向零点校准脚本说明

## 1. 目的

`tools\canopen_position_debug\steer4_zero_calibration_debug.py` 用 CAN 分析仪验证四个转向电机 Node5、Node6、Node7、Node8 的零点搜索流程，并作为 ECU 三击 B1 找零功能的参考实现。

脚本默认 dry-run，不会发真实运动命令；必须显式加 `--allow-motion` 才会动电机。正式清零方式不是驱动器 reset，也不是 `0x607C home offset`，而是在接受的机械零点位置写 `0x6064:00 = 0`。不采用 `0x607C home offset` 作为正式方案。

## 2. 当前算法

1. 四个转向轴进入 CANopen Profile Velocity 模式。
2. 每个阶段开始前都执行：
   - NMT Operational；
   - `0x6040 = 0x0080` 清故障；
   - `0x2300 = 0x001E` 选择 CANopen 控制；
   - `0x6060 = 3` 速度模式；
   - 设置 `0x6081/0x6083/0x6084`；
   - `0x6040: 0x0006 -> 0x0007 -> 0x000F` 重新使能。
3. 左限位方向按实车镜像关系配置：
   - Node5：`+`
   - Node6：`-`
   - Node7：`+`
   - Node8：`-`
4. 找限位使用两段速度：
   - 第一段：`1600000`
   - 第二段：`1120000`，即第一段的 70%，在单方向行程超过 `2400000 count` 后启用。
5. 堵转/限位判据：
   - 电流达到 `900`，即 9A，立即确认限位并对该轴发 0 速；
   - 或电流达到 `750`，即 7.5A，持续 `150ms` 后确认限位；
   - 单方向行程超过 `4000000 count` 仍未确认，认为异常并安全停止。
6. 四轴左限位完成后，不再根据未知零点“退回安全区”，而是清故障、重新进入速度模式，直接从左限位搜索右限位。
7. 右限位方向是左限位方向取反。
8. 左右限位都完成后，计算每轴中值：

```text
center = (left_limit + right_limit) / 2
```

9. 回中使用速度模式闭环回到各自中值位置，不使用 Profile Position 回中；速度分三段：
   - 误差 `> 500000 count`：`1600000`
   - 误差 `50000..500000 count`：`700000`
   - 误差 `< 50000 count`：`180000`
10. 到 `±10000 count` 或检测到过零后，连续稳定 2 次即停该轴，避免在中点附近来回振荡。
11. 正常回中完成后，写 `0x6064:00 = 0`。
12. 如果回中超时，脚本默认 `--return-timeout-action write-current-zero`：停止所有轴，把能读到的当前位置作为当前零点写 `0x6064=0`。这是现场应急策略；如果需要严格标定，可改为 `--return-timeout-action fail`。
13. 可选执行 `0x1010:01 = 0x65766173` 保存驱动器参数。

## 3. 推荐命令

CAN 分析仪 CAN1 接转向 CANopen 网络时，先 dry-run：

```powershell
python tools\canopen_position_debug\steer4_zero_calibration_debug.py
```

真实找零并写当前位置为 0：

```powershell
python tools\canopen_position_debug\steer4_zero_calibration_debug.py `
  --bus can1 `
  --allow-motion `
  --set-current-position-zero `
  --log-dir tmp\steer_zero_field
```

如果需要保存到驱动器参数区：

```powershell
python tools\canopen_position_debug\steer4_zero_calibration_debug.py `
  --bus can1 `
  --allow-motion `
  --set-current-position-zero `
  --save-drive-parameters `
  --log-dir tmp\steer_zero_field_saved
```

如果实测左右方向与当前配置不一致，只改 `--left-signs`，不要改控制流程：

```powershell
--left-signs 5:1,6:-1,7:1,8:-1
```

## 4. 输出文件

默认保存到：

```text
out/steer4_zero_calibration_YYYYMMDD_HHMMSS/
  events.json
  summary.json
  steer_zero_calibration.json
```

`steer_zero_calibration.json` 包含：

- `left_limit_counts_by_node`
- `right_limit_counts_by_node`
- `midpoint_counts_by_node`
- `span_counts_by_node`
- `midpoint_reached_position_counts_by_node`
- `position_counts_after_zero_write_by_node`

## 5. ECU 接入约束

ECU 的找零流程必须由 CAN2 motion task 独占执行：

- 找零期间禁止普通遥控转向 PDO；
- 找零期间禁止行走 PDO；
- 所有速度 PDO 由 CAN2 motion task 统一发；
- 每个阶段必须清故障并重新速度模式使能；
- 左右限位使用每轴方向配置；
- 回中使用三段速度，近中点才用第三段慢速；
- 写 `0x6064=0` 前必须先发 0 速并等待上一组 PDO 完成；
- 不允许通过驱动器 reset 找零，因为 reset 会破坏当前位置参考。

遥控触发条件：

- B1 为 CH10；
- HOME 必须在中位；
- B1 在 `2000ms` 窗口内短按 3 次；
- 触发后 ECU 持有找零请求，直到 CAN2 找零状态机完成或失败。

## 6. 安全注意

- 9A 是立即保护阈值，不再使用 15A；
- 找限位时每个轴独立完成，完成轴立即 0 速，其它轴继续；
- 阶段之间必须清故障；
- 任一轴无反馈、CAN2 bus-off、PDO 发送失败或超行程，必须安全停止；
- `--return-timeout-action write-current-zero` 是现场应急策略，会把当前位置作为零点，使用前必须确认机械位置可接受；
- 严格标定时应使用 `--return-timeout-action fail`，避免将错误位置写成零点。
