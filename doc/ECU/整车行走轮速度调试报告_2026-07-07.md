# 整车行走轮速度调试报告 2026-07-07（历史悬空测试）

> 本报告记录当日 2400 rpm / 0.84 m/s 台架结果，不是当前运行上限。当前参数以
> `ecu/config/include/ecu_config.h` 为准：CAN2 行走/转向和 CAN3 抬升伺服上限
> 3000 rpm，整车遥控限幅 0.50 m/s；Node13 液压站仅允许反转，最高 2400 rpm。

## 1. 结论

行走轮速度链路本轮通过悬空测试：

- Node1、Node2、Node3、Node4 当日均可单轮运行到 `0.84 m/s`，接近当时 `2400 rpm` 调试上限。
- 四轮同步直行 `0.10 → 0.84 m/s` 阶梯测试通过。
- 全部测试均未出现 EMCY。
- 全部测试结束后 0x2183 故障锁存为 `0x00000000`。
- 全部测试结束后 0x606C 实际速度回到 `0`。
- 车辆正前进方向的驱动器速度符号已确认并写入代码：
  - Node1：正转
  - Node2：反转
  - Node3：反转
  - Node4：正转

## 2. 本轮代码修正

### 2.1 行走轮硬件方向符号

高层控制仍使用车辆坐标系：

- `target_wheel_speed_mps > 0` 表示车辆向车头正方向运动。

硬件输出到驱动器 0x60FF 前乘每轮方向符号：

```text
Leg1 / Node1 front-right: +1
Leg2 / Node2 front-left : -1
Leg3 / Node3 rear-left  : -1
Leg4 / Node4 rear-right : +1
```

对应代码：

- `ecu/config/include/ecu_config.h`
- `ecu/config/src/ecu_config.c`
- `ecu/devices/src/motion_device.c`
- `tools/canopen_motion_debug/motion8_remote_sim_debug.py`

### 2.2 调试速度和加速度限制

- 当日调试最高电机转速：`2400 rpm`。
- 轮胎直径：`580 mm`。
- 行走轮减速比：`86.6:1`。
- 计算得到最高车辆线速度约：`0.842 m/s`。
- 0x6083/0x6084 当前调试加速度：`200000 count/s²`，约 `20 rps²`。
- 加速度硬上限：`500000 count/s²`，即 `50 rps²`。

## 3. 测试环境

- CAN 分析仪 CAN1 接 ECU CAN2 / 行走转向 CANopen 网络。
- 行走轮悬空。
- 使用 Python 脚本直接通过 CAN 分析仪发送 CANopen RPDO/SDO。
- 本轮行走速度测试不发送转向 RPDO。
- 驱动器工作模式：
  - Node1-4：Profile Velocity，RPDO0 = `0x6040 + 0x6060(mode=3) + 0x60FF`

## 6. 后续建议

本报告只覆盖行走轮速度链路。复杂四轮动作联调结果见
`doc/ECU/整车调试记录_2026-07-07.md`。

后续落地到 ECU 遥控闭环时，建议按以下顺序：

1. 单独确认四个转向轴的机械零点、方向、软件限位和当前位置反馈。
2. 转向轴零点确认后，做低速正 Ackermann：
   - 速度建议从 `0.10 m/s` 开始。
   - 转向角建议从 `5°` 开始。
3. 正 Ackermann 通过后，再测：
   - 反 Ackermann
   - 蟹行
   - 自转
4. 每次组合动作仍保留：
   - EMCY 统计
   - 0x2183 故障锁存
   - 0x6041 状态字
   - 0x606C 实际速度
   - 0x6064 实际位置
